# ECILA 3.0

ECILA is a multi-user AI workspace with authentication, projects, task history, multi-provider AI orchestration, research, files, voice, image analysis, document generation, background workers, notifications, and an admin control center.

## Release
ECILA 3.0.0

## Quick checks
- `npm run verify`
- `npm run release-check`
- `npm run preflight`
- `npm run build`

Production requires PostgreSQL, private S3-compatible storage, transactional email, at least one AI provider, and queue-mode workers.

See `docs/FINAL_HANDOFF.md` and `docs/RELEASE_VERIFICATION.md` for deployment and verification details.
